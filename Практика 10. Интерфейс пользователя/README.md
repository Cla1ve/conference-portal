# Практика 10. Разработка интерфейса пользователя

## Что сделано

1. **Вёрстка страниц по ТЗ.** Свёрстаны все страницы из списка практики 6: главная, регистрация, вход, мои заявки, новая заявка (она же форма изменения), личный кабинет, панель администратора. Шаблоны в `frontend/templates`.
2. **HTML, CSS, JavaScript.** Общий каркас `base.html`, стили в `style.css` (переменные для цветов, сетка карточек на `grid`), скрипты без библиотек: `common.js`, `auth.js`, `request.js`, `dashboard.js`, `admin.js`.
3. **Адаптивная вёрстка для 390×844.** Медиа-запросы на 800 и 480 px: меню превращается в «бургер», формы и фильтры идут в одну колонку, карточки на всю ширину, кнопки не ниже 44 px.
4. **Кроссбраузерность.** Проверил Chrome 155 и Edge 155 (скрипт на Selenium открывает одни и те же страницы в двух браузерах и считает горизонтальное переполнение и ошибки в консоли). Результат ниже, полный в `cross_browser_result.json`.
5. **Коммиты** в репозитории.
