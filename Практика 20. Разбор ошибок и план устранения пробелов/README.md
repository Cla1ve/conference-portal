# Практика 20. Разбор ошибок и итоговое консультирование

Документ с разбором: `Разбор_ошибок_и_план.md`, скриншот документа: `скриншот_документа.png`.

## Что в документе

1. **Основа разбора.** Практика 19 (пробный экзамен) в мой набор не входит, поэтому результатов по ней нет. Разобрал реальные ошибки из практик 1-18 и сверил проект с критериями оценивания из списка практических работ.
2. **15 ошибок**, которые нашёл по ходу работы: что было, почему, как исправил и чем проверил (тест, скрипт или скриншот в папке нужной практики).
3. **Сверка с критериями** по блокам: база данных, модули, безопасность, дизайн, адаптивность, оптимизация, тестирование, вариативная часть.
4. **9 пробелов**, которые остались (например, нет защиты от перебора пароля, нет HTTPS, проверял только Chrome и Edge, GitHub Actions ещё не запускался на GitHub).
5. **План устранения** из 9 шагов, у каждого написано, как пойму, что он готов.
6. **Вопросы для итогового консультирования** преподавателю.

## Главный вывод

Больше всего ошибок оказалось на границах: данные проверялись только в браузере, а не на сервере, не были учтены крайние состояния в вёрстке (узкий экран, одна карточка в списке, пустой список), а часть значений была прописана прямо в коде вместо темы. Для каждой найденной ошибки сделал тест или скрипт, который её ловит.
