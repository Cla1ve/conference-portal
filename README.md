# Конференции.РФ

Учебный проект: портал, где пользователь подаёт заявку на проведение мероприятия в помещении, а администратор назначает мероприятие и закрывает заявку. После завершения пользователь может оставить отзыв.
Выполнил Маматисаков Элмурат, группа 4ИСП9-45 (МДК.09.01, практические работы 1-18 и 20).

Есть вторая тематика «Спорт.РФ» (аренда спортивных площадок), она включается переменной `THEME=sport`.

## Как запустить

Проверял на Python 3.12. Нужен SQLite 3.35 или новее (миграция 002 использует `DROP COLUMN`).

```
pip install -r requirements.txt
python init_db.py
python seed_demo.py
python app.py
```

Сайт откроется на http://127.0.0.1:5000.

Демо-аккаунты (только для проверки, настоящих данных нет):

| Роль | Логин | Пароль |
|---|---|---|
| администратор | Conf2027 | Demo77 |
| пользователь | elmurat2027 | Student2027 |

Спортивная версия:

```
set THEME=sport
set DATABASE=database\sport.db
set PORT=5001
python init_db.py
python seed_demo.py
python app.py
```

## Тесты

```
python -m unittest discover -s tests -t .
pip install -r autotests/requirements.txt
python -m pytest autotests -c autotests/pytest.ini --rootdir .
```

Первая команда запускает 33 модульных теста, вторая 12 тестов Selenium (нужен Chrome). Тесты работают с отдельной временной базой. Для спортивной темы перед запуском выставить `THEME=sport`.
Те же команды запускает GitHub Actions (`.github/workflows/tests.yml`).

## Структура

```

database/migrations/    001_init, 002_dictionaries, 003_indexes
frontend/               шаблоны, css, js (в static/dist лежат минифицированные версии)
tests/                  модульные тесты
autotests/              тесты Selenium (Page Object)
tools/                  вспомогательные скрипты: проверки, замеры, сборка
design/, docs/          макеты, исходная картинка
Практика NN. ...        папки с отчётами и скриншотами по практическим работам
```
