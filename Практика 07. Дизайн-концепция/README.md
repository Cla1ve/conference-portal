# Практика 7. Разработка дизайн-концепции веб-приложения

Дизайн делал в соответствии с корпоративным стилем из практики 6 (синий и оранжевый, Montserrat + Open Sans).
Макеты собраны в HTML/CSS: инструмент для прототипов у меня заменяет сам браузер, так макет сразу совпадает с тем, что будет на сайте.

## Что сделано

1. **Мудборд**: `01_мудборд.png`. Исходник `design/moodboard.html`. Ключевые слова: порядок, доверие, энергия. Фото зала и оранжевых кресел с сайта Pexels (бесплатная лицензия).
2. **Цветовая схема**: `02_цветовая_схема.png` (`design/palette.html`). Основной синий #1B3A5C, акцент #E8590C, фон #F4F6F9, цвета статусов. Контраст пар цветов посчитал по формуле WCAG: у основного текста 14,7 к 1, у белого на синем 11,6 к 1. У кнопок белое на оранжевом даёт 3,6 к 1, этого хватает для крупного жирного текста.
3. **Шрифтовая пара**: `03_шрифтовая_пара.png` (`design/typography.html`). Montserrat для заголовков, Open Sans для текста. Оба с кириллицей и свободной лицензией, лежат локально в `frontend/static/fonts`.
4. **Макеты страниц**: файлы 04-10 в этой папке. Это 7 страниц: главная, регистрация, авторизация, просмотр заявок, создание заявки, панель администратора, личный кабинет. Сами html-файлы лежат в `design/desktop/`.
5. **Согласование с корпоративным стилем.** Проверил по списку из практики 6: цвета, шрифты, логотип в шапке, скругления 8-12 px, статусы цветными плашками. Расхождений нет.

## Как получены макеты

Скрипт `tools/export_mockups.py` берёт шаблоны сайта, подставляет примерные данные и сохраняет статичные страницы в `design/desktop` и `design/mobile`. Если поменять шаблон, макеты можно собрать заново одной командой.
