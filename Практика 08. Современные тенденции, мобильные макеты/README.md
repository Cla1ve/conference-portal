# Практика 8. Дизайн с учётом современных тенденций (мобильная версия)

## 1. Тенденции, которые применил

| Тенденция | Как использовано |
|-----------|------------------|
| Минимализм | Один акцентный цвет, много свободного места, лишних декоративных элементов нет |
| Карточный дизайн | Заявки и мероприятия показаны карточками с мягкой тенью и скруглением |
| Микровзаимодействия | Кнопки приподнимаются при наведении и «нажимаются» при клике, поля с ошибкой слегка встряхиваются, всплывающие сообщения выезжают сбоку |

## 2. Макеты для телефона 390×844

Макеты лежат в `design/mobile/*.html`, это отдельные html-файлы под мобильную версию. На компьютере они показываются в узкой колонке 390 px, на телефоне занимают весь экран. Меню на узком экране складывается в «бургер», фильтры и поля формы идут друг под другом, у кнопок высота не меньше 44 px.

Файлы в этой папке:

- `01-07_мобильный_макет_*.png`: страница целиком (снято с масштабом 2x, ширина 780 px);
- папка `первый_экран_390x844`: то, что видно на экране сразу, без прокрутки.

## 3. Оптимизация изображений

| Файл | Было | Стало | Что сделал |
|------|------|-------|-----------|
| Иллюстрация зала | 2596 КБ (PNG 1600×1000) | 68 КБ JPEG и 25 КБ WebP (1120×700) | уменьшил размер, убрал зерно, сохранил с прогрессивной загрузкой |
| Логотип | | 0,3 КБ | сделан как SVG, масштабируется без потерь |
| Шрифты | 8 файлов woff2 | 4 файла | взял вариативные шрифты, один файл на все начертания |

На странице картинка подключена через `<picture>`: браузер берёт WebP, а если не умеет, то JPEG. Размеры `width` и `height` заданы, поэтому страница не «прыгает» при загрузке.

## 4. Проверка отображения на смартфоне

Открыл макеты в Chrome в режиме эмуляции устройства (Pixel 7, 390×844, плотность пикселей 2). Горизонтальной прокрутки нет, текст читается, кнопки нажимаются пальцем. Скриншоты в этой папке сделаны в этом же режиме. На реальном телефоне сайт открывается по адресу компьютера в локальной сети (`python app.py` с хостом 0.0.0.0).
