# Практика 17. Адаптация под различную тематику ИС

## Какую тематику выбрал

Второй вариант сайта: **«Спорт.РФ»**, аренда спортивных площадок. Логика та же (пользователь подаёт заявку, администратор назначает, потом отзыв), поэтому код не копировал. Вся тематика лежит в одном словаре `THEMES` в `backend/themes.py`, а включается переменной окружения `THEME=sport`. Для спорта сделал отдельную базу, чтобы не смешивать данные.

## Что поменял

| Что | Конференции | Спорт |
|---|---|---|
| Название и главный заголовок | Конференции.РФ, "Проведите своё мероприятие у нас" | Спорт.РФ, "Забронируйте площадку для тренировки" |
| Помещения (справочник) | Аудитория, Коворкинг, Кинозал | Спортзал, Бассейн, Футбольное поле |
| Способы оплаты | При очном посещении, СБП | На месте, СБП |
| Название второго статуса | Мероприятие назначено | Тренировка назначена |
| Кнопка в админке | Назначить мероприятие | Назначить тренировку |
| Цвета | синий `#1b3a5c`, оранжевый `#e8590c`, фон `#f4f6f9` | тёмно-зелёный `#0b3d2e`, зелёный `#2b8a3e`, фон `#f1f6f2` |
| Логотип | `logo.svg` | `logo_sport.svg` (тот же "диалог", но зелёный) |
| Картинка на главной | `hero.jpg` / `hero.webp` | фото стадиона `hero_sport.jpg` / `hero_sport.webp` |
| Демо-данные | хакатон, кинопоказ, встреча клуба | футбол, плавание, волейбол, баскетбол |

**Медиа-ресурсы.** Картинку на главную взял с Pexels (фото стадиона, номер 13434565), обрезал до 1120x700 и сохранил как `hero_sport.jpg` (около 137 КБ) и `hero_sport.webp` (около 92 КБ). Оригинал лежит в `docs/img_source/`.

**Текстовое наполнение.** Когда начал менять слова, оказалось, что часть текстов зашита прямо в шаблонах и скриптах: "мероприятие" было в `index.html`, `dashboard.html`, `admin.js`, сообщениях проверки и в подсказке формы. Вынес их в тему (`event_acc`, `event_of`, `events_empty`, `event_placeholder`, `assign_button`, `statuses`, `hero_image`, `hero_alt`), а в общих сообщениях проверки оставил нейтральные слова ("Название: от 3 до 200 символов"). Заодно вылезла грамматика: фраза "администратор назначит тренировка" была неправильной, нужна форма винительного падежа, поэтому добавил отдельное поле `event_acc` ("тренировку").

**Дизайн.** Цвета и фон страницы приходят из `/theme.css` (переменные `--primary`, `--accent`, `--bg`). Сначала фон на спортивной теме остался синеватым: в `style.css` тоже была переменная `--bg`, и она перебивала тему. Убрал её оттуда, теперь фон задаёт только тема.

**Названия статусов** хранятся в таблице `status`, поэтому при создании базы для спорта `init_db.py` меняет название второго статуса на "Тренировка назначена".

## Как запустить

```
set THEME=sport
set DATABASE=database\sport.db
set PORT=5001
python init_db.py
python seed_demo.py
python app.py
```

Обычная версия работает как раньше на порту 5000.

## Проверка

- по тексту всех страниц спортивной версии автоматически проверил, что слов "мероприятие" и "конференция" не осталось (скрипт ничего не нашёл);
- на конференционной теме после правок всё работает как раньше: 27 прежних модульных тестов проходят;
- сквозная проверка спортивной версии и тесты на ней описаны в практике 18.
