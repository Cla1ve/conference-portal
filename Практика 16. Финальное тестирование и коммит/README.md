## Какие ошибки нашёл и исправил

Это три дефекта из отчёта по тестированию (задание "Тестирование информационных систем"). Для каждого сначала написал тест, он упал, потом исправил код, и тест стал зелёным (`01_тесты_до_исправления_3_падают.png`, `10_тесты_после_исправления_все_проходят.png`).

| Баг | Что было | Что сделал |
|---|---|---|
| BR-001 | у сайта не было значка, браузер получал 404 на `/favicon.ico`, в консоли красная ошибка | в `base.html` добавил `<link rel="icon">` на логотип темы, добавил маршрут `/favicon.ico` (перенаправляет на значок) |
| BR-002 | сервер принимал пароль из 8 пробелов, если отправить запрос мимо формы | в `validators.check_password` добавил проверку, что в пароле есть непробельные символы |
| BR-003 | можно было подать заявку на сегодня на время, которое уже прошло | новая функция `check_not_past(date, time)`, она вызывается в `Request.validate` |

Для BR-002 и BR-003 повторил запросы скриптом `tools/repro_defects.py`: теперь сервер отвечает 400 и понятным сообщением (`11_дефекты_BR-002_BR-003_после_исправления.png`). DevTools после исправления: значок `logo.svg` загружается со статусом 200 (`08_devtools_сеть_значок_сайта_загружается.png`), консоль чистая.
